# راجع الإضافة قبل ما تثبّتها

## النص
(0-5 ثانية)
«الإضافة اللي تثبّتها لوكيل الذكاء الاصطناعي تنفّذ كود على جهازك»

(6-15 ثانية)
«ملف الأمان في أشهر حزمة إضافات لـ Claude Code يقول إن مكوناتها ممكن تنفّذ كود، ويطلب منك تراجعها قبل التثبيت.»

(16-30 ثانية)
«ومشروع OpenClaw يقول نفس الشي في ملف الأمان عنده: الإضافة تنحمّل داخل البرنامج وتنعامل ككود موثوق، يعني تاخذ نفس صلاحياتك.»

(31-40 ثانية)
«في المحاسبة ما يترحّل قيد بدون مراجعة. ونفس الشي هني: أي إضافة تنفّذ كود، تراجعها قبل ما تثبّتها.»

## نص المنشور
أمان إضافات الذكاء الاصطناعي: ليش لازم تراجع الإضافة قبل التثبيت.
